## Methodology

1. **Interview loop** (Wonder → Reflect → Refine → Restate) converges goal + AC with the user
2. **RALPH Wiggum self-referential loop** (Stop hook) iterates WebSearch/WebFetch until AC satisfied
3. **`verify-ac.sh`** gates every iteration — exit 0 only if ALL AC PASS
4. `<promise>RESEARCH COMPLETE</promise>` is verified against the AC verifier before the hook releases
